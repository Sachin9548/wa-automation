# WhatsApp Business Automation SaaS

## 🎯 What This Is

A **FREE WhatsApp automation platform** for businesses (restaurants, e-commerce, shops) to:
- Receive customer messages automatically
- Respond with AI-powered answers
- Take orders via WhatsApp
- Send marketing messages
- **All without any WhatsApp API costs!**

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start WhatsApp Bot
```bash
npm run whatsapp
```

### 3. Scan QR Code
- Browser window opens automatically
- Scan QR code with your business WhatsApp
- Wait for "✅ WhatsApp Web Client is ready!"
- **Done! Bot is now active**

### 4. Test It
Send these messages to your business WhatsApp:
- "Hi" → Welcome message + menu
- "Menu" → Full menu display
- "Pizza" → Order confirmation
- "Burger" → Order confirmation

## 📱 How It Works

```
Business Owner                    Customer
     ↓                               ↓
Scans QR code (once)          Sends WhatsApp message
     ↓                               ↓
Connected forever!            Gets instant AI response
     ↓                               ↓
Can send to anyone            Can place orders
```

**Key Point:** Business owner scans QR **once**, then bot works forever!

## 🔧 Troubleshooting

**QR code not showing?**
- Check if browser opened
- Look for QR code in browser window
- Check console for errors

**Messages not received?**
- Make sure QR is scanned
- Wait for "✅ WhatsApp Web Client is ready!"
- Check if WhatsApp is connected on phone

**Bot not responding?**
- Check console for errors
- Make sure bot is running (`npm run whatsapp`)
- Try restarting the bot
